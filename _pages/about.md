I'm a third-year PhD student in the [ProgSys](https://cseweb.ucsd.edu/groups/progsys/) group at UCSD, advised by [Loris D'Antoni](https://cseweb.ucsd.edu/~ldantoni/) and [Nadia Polikarpova](https://cseweb.ucsd.edu/~npolikarpova/).
My research focuses on building programming abstractions that make it easier to build robust software systems.
Much of my work is motivated by the increasing role of LLMs in modern software.
Examples of projects include:

- [Language-Based Agent Control](https://arxiv.org/abs/2605.12863) (NeurIPS 2026) is a framework for applying language-based security techniques _off-the-shelf_ to code containing agentic components.
- [ChopChop](https://arxiv.org/abs/2509.00360) (POPL 2026) is a framework for defining streaming program analyses, which can analyze programs at the token level, as they are being written by an LLM.
